# DEAVOUR — Game QA Portfolio Website

A responsive, dark cinematic portfolio website using matte black `#0D0D0D` and metallic gold `#D4AF37`.

## Files
- `index.html` — content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `assets/deavour-logo.png` — supplied DEAVOUR emblem

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your `deavour.github.io` repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for deployment, then open `https://YOUR-GITHUB-USERNAME.github.io/`.

## Important accuracy note
Game titles in this site reflect gameplay familiarity shared by the owner. Test cases and bug report formats are practice work; do not describe them as completed execution or verified defects unless personally tested. Download links are placeholders until final PDF/XLSX files are added.
